# WiCyS India – Static Prototype

Single-page static prototype for the WiCyS India Affiliate website, built with plain HTML and CSS.

- Implements the Week 2 wireframe: fixed header, hero banner, three content sections, and footer.
- Uses WiCyS brand colors (purple, white, green, gray) and Google Fonts (Montserrat, Roboto).

# Live site

Deployed on Vercel: https://wicys-website-design.vercel.app/
